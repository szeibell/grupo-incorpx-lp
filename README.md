# Grupo Incorpx — Landing Page Institucional

Site estático (HTML, CSS e JS puros, sem dependências).

## Estrutura
- `index.html` — página completa
- `img/` — logos, fotos e o vídeo do banner (`hero-simbolo.mp4`)

## Publicar no GitHub Pages
1. Envie todos os arquivos para a raiz do repositório (branch `main`).
2. Em **Settings → Pages**, escolha *Deploy from a branch*, branch `main`, pasta `/ (root)`.
3. O site fica em `https://<usuario>.github.io/<repositorio>/`.

## Pendências
- Destinos dos botões das marcas e da Política de Privacidade.
- Envio real do formulário de contato (hoje só valida e mostra a mensagem de sucesso).
- Texto definitivo da Special X.
